# Ship It (Get Shit Done)

Fast execution mode for rapid implementation. Use when you need to ship quickly.

## Usage
/ship <task-description>

## Process
1. Clarify scope (1 question max)
2. Start immediately
3. Ship minimal working version
4. Iterate if needed

## Output
Working code, shipped fast.

---

$ARGUMENTS

Execute the task above in GSD mode.

Use the `get-shit-done` skill:

### Rules
1. **No over-planning** - Understand enough to start, then start
2. **Minimal scope** - What's the smallest thing that works?
3. **Ship fast** - Working > perfect
4. **Iterate** - v0.1 now beats v1.0 never

### Execution
1. If requirements are clear enough, start immediately
2. If one critical question, ask it
3. Implement in 15-minute sprints
4. Test quickly, fix quickly
5. Commit and move on

### Quality Bar
- It works
- It doesn't crash
- It handles obvious errors
- It's readable enough

### Not Acceptable
- Security vulnerabilities
- Data loss risks
- Complete lack of error handling

Execute now. Ship it.
