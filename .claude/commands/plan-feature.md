# Plan Feature

Create a detailed implementation plan for a new feature.

## Usage
/plan-feature <feature-description>

## Process
1. Analyze the feature request
2. Break down into user stories
3. Define technical approach
4. List files to create/modify
5. Define testing strategy
6. Identify risks

## Output
A complete implementation plan ready for execution.

---

$ARGUMENTS

Create an implementation plan for the feature described above.

Use the `writing-plans` skill to structure the plan with:
- Overview (goal, success criteria, non-goals)
- User stories with acceptance criteria
- Technical approach and key decisions
- Implementation steps (phased)
- File changes (new and modified)
- Testing strategy
- Risks and mitigations

Consider MTA Website context:
- Frontend: Next.js 15 + React 19 + Tailwind CSS
- Backend: Express.js + MongoDB
- Brand color: #6B1A1A

Output the plan in markdown format.
