# Brainstorm

Generate ideas and explore approaches for a problem or feature.

## Usage
/brainstorm <topic>

## Process
1. Divergent thinking - generate many ideas
2. Explore different approaches
3. Evaluate options
4. Recommend best approach

## Output
Structured brainstorm with recommendation.

---

$ARGUMENTS

Brainstorm the topic specified above.

Use the `brainstorming` skill:

### Phase 1: Divergent Thinking
Generate as many ideas as possible:
- No judgment
- Wild ideas welcome
- Build on ideas

### Techniques
- **Mind Mapping**: Branch out from central concept
- **"How Might We"**: Frame as opportunity questions
- **Reverse**: What would make this terrible? Flip it.
- **Analogies**: How do others solve similar problems?

### Phase 2: Evaluate
Rate ideas on:
| Idea | Impact | Effort | Risk |
|------|--------|--------|------|

### Phase 3: Recommend
Select top 3 approaches with rationale.

### Output Format
```markdown
## Brainstorm: [Topic]

### Ideas Generated
1. [Idea 1]
2. [Idea 2]
...

### Top 3 Approaches

#### Approach 1: [Name]
- Description:
- Pros:
- Cons:
- Effort: Low/Medium/High

#### Approach 2: [Name]
...

### Recommendation
[Which approach and why]

### Next Steps
1. [Action item]
2. [Action item]
```
